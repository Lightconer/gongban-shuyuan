如何在阅读 App 中使用

  1. 下载书源文件（任选其一或都导入）：
    · 公版古籍_维基文库.json（章节化，适合整本长篇小说）
    · Gutenberg_公版中文书.json（国内可达，可直接搜索公版书）
  2. 阅读 App（如 Legado/阅读）→ 我的 → 书源管理 → 右上角菜单 → 网络导入，粘贴书源 JSON 直链。
  3. 也可在书源内直接输入公版书籍页面地址打开对应书籍（如 https://zh.wikisource.org/wiki/紅樓夢 或 https://www.gutenberg.org/ebooks/24264 ）。
  4. 规则为 v0.1，个别书籍结构特殊时可在书源管理里微调。

网络提示：本机实测维基文库在部分国内网络不可达，若无法访问请改用 Gutenberg 书源；GitHub Actions 运行在境外服务器，两类来源都会被正常校验。

自动更新机制

仓库内 .github/workflows/update.yml 每天定时执行 scripts/validate.py， 按站点自动校验每本书是否可达、是否含有效正文，刷新本页数据与 书单.md；状态有变化时自动提交，并部署到 GitHub Pages。
